# Cobblemon Smartphone: Odyssey Quests App

Adds a "Open Quests" App to Cobblemon Smartphone to open the Heracles/Odyssey Quests UI on Fabric/NeoForge.

Works only client-side.

![sample](https://raw.githubusercontent.com/hudsonm62/CobblemonSmartphoneQuestsApp/refs/heads/master/.github/sample.png)

For pack makers, it's highly recommended to use with the [Cobblemon Quest Bridge](https://modrinth.com/project/eLwyHtUJ) mod for a completed Cobblemon-integrated Odyssey Quests experience.
